## 结论先行

| 维度 | 核心发现 |
| --- | --- |
| 认知 | 健康食品核心属性认知清晰：69.23% 认可“有机/绿色/无公害”，62.39% 认可“低糖/低盐/低脂”；但对膳食指南、特殊人群标准的认知不足 |
| 知行偏差 | 超六成受访者健康食品月支出占食品总支出不足 30%；约 40% 属“高认知低行为”，约 15% 属“低认知高行为” |
| 支出与渠道 | 38.46% 每月健康食品固定支出不足 100 元；线上平台（60.68%）已超过传统超市（47.86%）成为主渠道 |
| 主要制约 | 价格高 47.01%、购买不便 45.30%、口味差 44.44%；坚持层面以“烹饪耗时”（62.39%）和时间成本（64.96%）为首 |
| 医疗减负 | 个人年均减负约 **682 元**；按 60% 报销比例折算，医保基金人均减负 **409 元**；公共医疗资源人均节约 **205 元**，每千人年均社会减负 **129.6 万元** |
| 服务与营销 | 仅 15.38% 定期购买营养师/定制餐等专业服务；广告最吸引人的是营养成分可视化（68.38%）与真实用户体验（66.67%） |

**策略建议（报告第八章）**：居民端做精准科普、简化实践路径；企业端做高性价比产品、改进口味与便捷形态、强化认证与溯源、线上线下一体化；政府端做标准与标签规范、社区营养服务、冷链等基础设施与激励机制。

## 研究问题与背景

“健康中国”战略与“体重管理年”专项行动把饮食干预推到前台，但城市居民普遍存在“知而不行”：知道健康饮食重要，却因价格、时间、便利性难以持续。报告要回答四个问题：

1. 城市居民对健康饮食的认知处于什么水平，不同年龄、收入、性别群体差异如何？
2. 实际消费行为（支出、渠道、服务使用、健康餐频次）呈现什么特征？
3. 认知与行为为何偏离，哪些因素主导决策？
4. 健康饮食能给个人、医保基金和社会医疗系统带来多大减负效应？

分析框架为“认知—行为—医疗影响—市场响应”全链条，对应报告第一章至第八章。

## 问卷设计与样本

- **结构**：6 个模块、25 题——基本信息、健康饮食认知、行为习惯、决策因素、医疗支出关联、需求与营销响应；题型为单选、多选与 1–5 级量表。
- **发放**：线上（问卷星、微信社群）+ 线下（商场、社区、写字楼、学校）；设置地域限制、IP 限制与逻辑校验。
- **预调查**：回收 60 份，量表题 Cronbach's α 均在 0.8 以上，KMO 值 0.78，据此修订题项后正式发放。
- **正式样本**：两套问卷，各发放并回收有效问卷 **244 份**和 **117 份**，合计 **361 份**，有效回收率 100%。
- **样本结构（报告表 2）**：女性 54.9%；18–35 岁 57.8%，36–45 岁 30.3%，46 岁及以上 11.9%；本科 62.7%；月收入 3000–8000 元 52.1%。

> 本仓库只保留 **117 份**子样本的逐条脱敏数据。244 份样本的逐条数据未留存，因此报告中的部分图表（如报告表 2 的人口结构、部分交叉分析）无法仅凭本仓库数据完整复现。

## 方法与分析框架

报告实际采用的方法：

| 环节 | 方法 |
| --- | --- |
| 数据质量 | 预调查信效度检验（Cronbach's α、KMO）；地域/IP 限制与逻辑校验 |
| 描述统计 | 各题频数、占比；支出、频次、渠道的分布结构 |
| 差异分析 | t 检验、方差分析，比较年龄、收入、性别、健康状况群体在认知与行为上的差异 |
| 相关性分析 | 认知水平、支付意愿、行为践行与医疗支出之间的关联强度 |
| 聚类分析 | 按“认知—行为”二维划分四类人群：高认知高行为、高认知低行为、低认知高行为、低认知低行为 |
| 量化测算 | 个人减负 → 医保基金（按 60% 报销比例）→ 公共医疗资源（按个人减负的 30%）→ 5 年累计效应 |

**要用数据**：

`respondent_id` 为重新编号的匿名 ID；`duration_sec` 为答题用时（秒），可用于剔除过快作答的样本。各列含义见 [数据说明](data/数据说明.md)。

**能复现到什么程度**：117 份子样本的描述统计可由 CSV 逐项复算，结果与报告表 6（广告渠道）及 6.1–6.5 中基于 117 份的占比一致；涉及 244 份样本的分析、信效度检验与聚类结果无法完整复现。早期版本（2025-12 的 1.17 MB 稿、初稿及压缩包内的分析备忘）未收录。
