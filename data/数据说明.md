# 数据说明

## 文件

`survey_117_anonymized.csv`：117 行 × 62 列，UTF-8 编码，首行为列名。

数据来源为市场调查与分析大赛项目的问卷收集表（117 份有效问卷）。报告主分析使用两套问卷（244 份 + 117 份），本文件仅覆盖其中 117 份子样本。

## 脱敏口径

已删除以下字段：

| 原字段 | 处理 |
| --- | --- |
| 序号 | 重新编号为 `R001`–`R117`，不保留提交顺序 |
| 提交答卷时间 | 删除（精确到秒，可与其他信息组合定位个人） |
| 来源 | 删除（微信 / 互填问卷，属准标识信息） |
| 来源详情 | 删除（原始值全为 N/A） |
| 来自IP | 删除（含 IP 与城市） |

保留 `duration_sec`（答题用时，秒），仅用于数据质量筛查，不具身份识别性。原始数据不含姓名、手机号、微信号、身份证号字段；本仓库不提供未脱敏原始文件。
